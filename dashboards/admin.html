🧪 Testing Guide — Admin Dashboard

What this page is: This is the main control panel. Only admins can see it. From here you can manage everything in the system.

Manage Users — Activate new accounts, deactivate old ones, and assign roles (volunteer, staff, or admin).
Departments — Create and manage the departments that volunteers and staff belong to.
Review Hours — Approve or reject hours submitted by volunteers and staff. Hours only count once approved.
Reports — See a summary of all hours and export them.

How to test: Click each button to open that section. You can come back to this page anytime using the browser's back button.
