🧪 Testing Guide — Departments

What this page is: This is where you create and manage departments. Departments are the groups that volunteers and staff belong to — for example: Security, Registration, or Operations.

Add Department — Click this button to create a new department. You will give it a name and a short code (example: SEC01 for Security).
The code — This is a short unique label for the department. Keep it simple and easy to remember.
Edit — Click Edit on any row to rename a department, change its code, or mark it as inactive.
Inactive departments — These are hidden from regular use but their data is kept.

How to test: Click Add Department, fill in a name and code, and save it. Then try editing it.
