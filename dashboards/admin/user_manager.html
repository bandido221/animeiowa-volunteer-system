🧪 Testing Guide — User Manager

What this page is: This is where you manage everyone who has signed up. You can find any user, turn their account on or off, and set what they are allowed to do.

The top table — Shows all users. Use the search box to find someone by name or badge number. Use the dropdowns to filter by role or status.
Edit button — Click Edit on any row to change that person's name, role, badge number, department, or active status.
Active / Inactive — New sign-ups start as Inactive. You must set them to Active before they can log in.
The bottom table (New Sign-ups) — Shows people who created an account but have not been set up yet. Click Add to complete their profile.

How to test: Find a test user in the list, click Edit, change their role or status, and click Save.
